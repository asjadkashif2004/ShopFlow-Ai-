# ShopPilot AI

An AI shopping assistant: tell it what you need and your budget, five agents research and compare
the catalog in front of you, and you approve the purchase with PayPal Sandbox.

## How a mission works

| Agent | What it does | Powered by |
|---|---|---|
| Intent Agent | Turns the request into must-haves, preferences and a budget, validated against the catalog schema | Groq `openai/gpt-oss-120b` (rules fallback) |
| Search Agent | Filters products with SQL on Supabase (JSONB specs, tag arrays) | Supabase Postgres |
| Budget Agent | Splits matches into within budget and close calls just over | Python |
| Comparison Agent | Transparent scoring: value, rating, fit and specs, with reasons and trade-offs | Python |
| Explainer Agent | Writes the recommendation using only computed facts; any dollar amount not in the facts is rejected | Groq (template fallback) |

Checkout uses PayPal Orders v2 through the official **PayPal Server SDK** (generated by APIMatic).
The price always comes from the database, never from the browser, and capture is safe to retry.

## Run locally (Windows)

1. Put your keys in `key/All keys.txt` (the folder is git-ignored). See [docs/keys-setup.md](docs/keys-setup.md).
2. Supabase, once: open **SQL Editor → New query**, paste all of [supabase/shoppilot_setup.sql](supabase/shoppilot_setup.sql)
   and click **Run**. It creates the tables with Row Level Security, the access rules for the publishable key,
   and the 60-product seed. Regenerate it with `backend/.venv/Scripts/python backend/scripts/build_supabase_sql.py`.
   Already ran it before product photos existed? Run [supabase/002_product_images.sql](supabase/002_product_images.sql)
   once as well; it only adds the photo columns. Product photos come from [Unsplash](https://unsplash.com)
   (free to use) and each one credits its photographer.
3. Backend (port 7860):

   ```bash
   python -m venv backend/.venv
   backend/.venv/Scripts/python -m pip install -r backend/requirements.txt
   backend/.venv/Scripts/python -m uvicorn app.main:app --app-dir backend --port 7860 --reload
   ```

4. Frontend (port 5173, proxies `/api` to the backend):

   ```bash
   npm --prefix frontend install
   npm --prefix frontend run dev
   ```

Open <http://localhost:5173>. Without the backend the UI runs a full in-browser demo.
Restart the backend after adding keys. It logs which keys it found (never their values) and
reports `database`, `ai` and `paypalMode` at `GET /api/config`.

## API

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/config` | PayPal client ID, payment mode, database and AI in use |
| POST | `/api/missions` | `{ "query": "…" }` → Server-Sent Events stream of agent steps and the result |
| POST | `/api/orders` | `{ "productId", "missionId" }` → creates a PayPal order at the database price |
| POST | `/api/orders/{paypalOrderId}/capture` | Captures an approved order |
| GET | `/api/orders` | Recent orders |

Smoke test a running backend: `backend/.venv/Scripts/python backend/scripts/smoke.py`
